## 📄 Sobre o projeto

Portfólio pessoal de **Natan Sousa**, desenvolvedor de sistemas, feito com **Next.js, TypeScript e Tailwind CSS**.

O site apresenta quem eu sou, as ferramentas que utilizo, os projetos em destaque e um formulário para contato, tudo em uma única página, com tema claro e escuro.

🌐 **Site:** [natan-portfolio.vercel.app](https://portfolio-natan7zz.vercel.app/)

## ✨ Funcionalidades

- 🌗 Tema claro e escuro, com a escolha salva no navegador
- 🖼️ Foto de perfil diferente para cada tema
- 🎬 Animações ao rolar a página: os blocos aparecem e somem conforme a rolagem
- 🛠️ Seção de conhecimentos com as ferramentas que eu uso
- 🗂️ Projetos em destaque, com banner, ano e tecnologias
- ✉️ Formulário de contato que envia a mensagem direto para o meu e-mail
- 💻 Logo estilo código e efeitos ao passar o mouse nos botões e links
- 📱 Layout responsivo, para computador e celular

## 🚀 Como usar

1. Acesse a aba [**Releases**](../../releases) e baixe o `.zip` do projeto.
ou
2. Clone o repositório:
   ```bash
   git clone https://github.com/Natan7zz/natan-portfolio.git
   ```
3. Entre na pasta e instale as dependências:
   ```bash
   cd natan-portfolio
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra [http://localhost:3000](http://localhost:3000) no navegador.

Para gerar a versão de produção, use `npm run build` e depois `npm start`.

> ⚠️ Se o site abrir com cores antigas depois de mudar a configuração, pare o servidor, apague a pasta `.next` e rode `npm run dev` de novo.
